# B站直播间礼物价值标注（电池）

在 B 站直播间**聊天栏的礼物播报**后面标注这份礼物值多少，默认用电池数表示。价格来自 B 站官方礼物面板接口，官方上新礼物后刷新网页即可拿到新价格；送礼面板与礼物列表保持 B 站原样，不会出现任何脚本加的内容。

> 1 元 = 10 电池。脚本只读取公开接口和页面内容做展示，不发送弹幕、不送礼、不改动 B 站页面业务逻辑。

## 功能

- **只标注观众送出的礼物**：标注挂在聊天栏的礼物播报后面；送礼面板、背包、礼物弹层、礼物榜里的礼物格子保持原样
- **价格在线同步**：每次打开页面强制从官方礼物面板接口拉取全量价格表，直播中每 30 分钟静默同步，遇到查不到价格的新礼物也会按需补拉；接口不可用时使用内置 89 件常见礼物的兜底价
- **官方上新礼物无需改脚本**：刷新一下网页就能拿到新礼物的价格
- **显示单位可选**：电池 / 人民币元 / 两者同时显示
- **价值口径可选**：本次总价（单价 × 数量）或单个礼物单价
- **连击实时更新**：Combo 数量变化时标注跟着刷新，可选显示「单价 × 数量 = 合计」明细
- **本场累计浮条**：可选在页面右下角显示本场礼物累计
- **免费与未知礼物**：免费礼物显示「免费 · 0电池」；查不到价格的活动 / 限定礼物可选显示「价格未知」；红包显示「金额不定」
- **网页内设置面板**：菜单点「展开设置」，在页面中央打开设置面板，全部配置与工具都在里面
- **深浅色适配**：徽章与设置面板跟随直播间配色，深色背景也保持可读

## 安装

1. 给浏览器装一个用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox / Safari 均有）
2. 安装脚本，两个地址任选（前者国内可直连）：
   - CDN：[bilibili-live-gift-value.user.js](https://cdn.jsdelivr.net/gh/kingsely666/bili-live-gift-value@main/bilibili-live-gift-value.user.js)
   - GitHub：[raw.githubusercontent.com](https://raw.githubusercontent.com/kingsely666/bili-live-gift-value/main/bilibili-live-gift-value.user.js)
3. 打开任意直播间，聊天栏出现礼物播报时自动生效

> 装好后在 Tampermonkey 管理面板确认「B站直播间礼物价值标注（电池）」已启用。

## 使用

| 操作 | 效果 |
| --- | --- |
| 菜单点「标注开关」 | 立即开关标注 |
| 菜单点「展开设置」 | 在网页中央打开设置面板，菜单标签变为「收起设置」，再点一次可关闭 |
| 在面板里改配置 | 改动先存草稿，页面上的标注保持当前设置 |
| 点面板「保存」 | 写入配置并重新标注聊天栏礼物 |
| 点「取消」、右上角 ×、面板外或按 `Esc` | 放弃本次未保存的改动 |
| 点面板「恢复默认」 | 把默认值填入表单，点「保存」后生效 |

设置面板里可以调整：启用标注、显示单位、价值口径、显示乘法明细、本场累计浮条、未知礼物也标注、自动同步新礼物。

面板「工具与状态」区提供三个按钮和一段运行状态：

- **刷新礼物价格表**：立即向官方接口重新拉一次全量价格表
- **重置本场累计**：把本场累计归零
- **复制运行状态**：复制房间号、价格来源、上次在线同步时间、已标注条数、本场累计与标注开关状态，便于排查问题

## 数据与隐私

配置与价格表只写在浏览器本地（Tampermonkey 的 `GM_setValue` / `GM_getValue`，不可用时回退到 `localStorage`）：

| 键 | 内容 |
| --- | --- |
| `blgv_cfg_v1` | 7 项设置 |
| `blgv_prices_v1_<房间号>` | 各房间的在线礼物价格表缓存，有效期 6 小时 |

网络请求只发往 `api.live.bilibili.com` 的公开只读接口：房间信息（`room/v1/Room/get_info`）与礼物面板（`xlive/web-room/v1/giftPanel/roomGiftList`），不需要登录、不携带账号凭据。不采集、不上报任何数据，不含统计代码和广告。

## 常见问题

**官方上新礼物后价格不对？**
刷新一下网页即可。脚本每次启动都会强制拉取在线价格表，不会被缓存挡住。

**某个礼物显示「价格未知」？**
多为活动、限定或盲盒礼物。脚本会自动补拉价格表；也可以在设置面板点「刷新礼物价格表」。开启「未知礼物也标注」时会显示提示，否则这条播报不标注。

**为什么送礼面板里的礼物没有标注？**
这是预期行为。脚本只标聊天栏里「观众送出礼物」的播报，送礼面板、背包、礼物榜保持 B 站原样。

**改了设置但页面没变化？**
面板里的改动需要点「保存」才会生效；保存后聊天栏的标注会重新计算。

**设置面板打不开？**
确认脚本已在 Tampermonkey 里启用，且用户脚本管理器支持 `GM_registerMenuCommand`。菜单里应有「标注开关」和「展开设置」两项。

**盲盒、红包怎么算？**
盲盒按购买价计算，爆出的礼物价值可能不同；红包金额由发送者设定，显示「金额不定」。
